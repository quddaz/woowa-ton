# 테코톤 프로젝트 제출용 문안

## 팀명

리뷰레이더

## 프로젝트명

PR-Explorer

## 1. 프로젝트 한 줄 소개

코드리뷰 학습 포인트를 빠르게 발견하도록 돕는 PR 탐색·요약 서비스입니다.

## 2. 프로젝트 사용자는 누구인가요?

- 우아한테크코스 크루
- 코드리뷰를 학습 자산으로 활용하고 싶은 주니어 개발자
- 팀 내 PR 흐름과 리뷰 품질을 빠르게 파악하고 싶은 리뷰어/리더

## 3. 어떤 목적으로 만들어졌나요?

- PR 본문, 리뷰 코멘트, 대화 맥락이 여러 곳에 흩어져 있어 학습 포인트를 찾는 데 시간이 오래 걸리는 문제를 해결하기 위해 만들었습니다.
- 많은 PR 중에서 "지금 읽으면 도움이 되는 리뷰"를 빠르게 선별하도록 돕는 것이 목표입니다.
- AI 요약/선별 기능을 통해 단순 열람이 아닌 **학습 중심 탐색 경험**을 제공하고자 했습니다.

## 4. 기능은 무엇이 있나요?

- PR 목록 조회
  - Open / Merged 상태 분리
  - 제목/작성자 검색
- PR 상세 확인
  - PR 본문
  - 리뷰/코멘트 타임라인
- AI PR 요약
  - 작성자의 고민점, 리뷰 요청 포인트 자동 요약
- 중요 코멘트 필터
  - 학습 가치가 높은 리뷰 코멘트만 추출
- 캐시 저장
  - Supabase를 활용해 재요청 시 응답 속도 및 비용 최적화

## 5. 다른 서비스와 차별화되는 본인 서비스의 강점은 무엇인가요?

- **학습 목적 최적화**: 단순 PR 뷰어가 아니라 "무엇을 배워야 하는지"를 중심으로 정보를 재구성합니다.
- **AI + 캐시 결합 구조**: 요약 품질과 응답 속도를 함께 고려한 실사용형 아키텍처입니다.
- **리뷰 큐레이션 경험**: 모든 코멘트를 다 읽지 않아도 중요한 피드백을 우선적으로 확인할 수 있습니다.
- **즉시 적용 가능성**: 기존 GitHub PR 워크플로를 바꾸지 않고 보조 도구로 바로 도입할 수 있습니다.
